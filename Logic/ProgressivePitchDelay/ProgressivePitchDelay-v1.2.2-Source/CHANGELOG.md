# Progressive Pitch Delay Changelog

## 1.2.2

- Added a Reset button that restores the factory Default preset.
- Added a Folder button that reveals the most recently used user-preset folder in Finder.
- Save and Load dialogs now remember the most recently used preset folder.
- Added preset-format version validation so presets from unsupported future formats are rejected safely.
- Saved preset files and project states now record the plug-in version that created them.
- Improved header layout at supported window sizes and added safer text scaling for the title and subtitle.
- Preset tooltips now show the complete user-preset name when the visible name is shortened.
- Kept DSP behaviour, factory presets, parameter IDs, and host automation mapping unchanged from 1.2.1.
